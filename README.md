# SoundCloud Desktop releases

Installers and in-app update files for SoundCloud Desktop (Windows). Get the installer from the newest release under **Releases**.

Once installed, the app updates itself: when a new version is out, a bar at the top of the app offers **Update now**. You can also use **Settings → About → Check for updates**.

Windows may show a SmartScreen warning the first time because the installer isn't code-signed: choose **More info → Run anyway**. Updates are verified with the app's own signing key before they install.
